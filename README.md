# spill-fra-mobil
Test av claude og github via mobil. Null pc oppsett. POC WIP

## Stjernefanger ⭐
Et lite mobilspill som fungerer som en PWA (kan legges på Hjem-skjermen på iPhone og spilles offline).

- Dra fingeren for å styre romskipet
- Fang ⭐ for poeng – fang mange på rad for combo (opptil x5)
- Unngå ☄️ – du har 3 liv
- 🛡️ gir skjold i 6 sekunder, ❤️ gir et ekstra liv

Kun HTML, CSS og JavaScript – ingen byggesteg.

### Publisere med GitHub Pages
1. Repo → **Settings** → **Pages**
2. Under *Build and deployment*: Source = **Deploy from a branch**, Branch = **main** / **(root)** → Save
3. Etter ca. ett minutt ligger spillet på `https://<brukernavn>.github.io/spill-fra-mobil/`

### Installere på iPhone
Åpne lenken i **Safari** → trykk **Del** → **Legg til på Hjem-skjerm**.
